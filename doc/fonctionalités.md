
# Liste des fonctionalités triés par rôle.

`Pour un client :`
    - créer son compte client
    - se connecter à son compte
    - se déconnecter de son compte
    - suprrimer définitivement son compte (avec obligation de n'avoir aucune reservation en cours)
    
    - dans le profil -> pouvoir modifier ses données personnelles :
        -> nom
        -> Prenom
        -> adresse
        -> numéro de téléphone
        -> code postale
        -> ville
        -> pays

    - dans le profil -> pouvoir modifier ses informations de connexion :
        -> nom d'identifiant
        -> mot de passe
    - remplir le pannier(rempli de une ou plusieurs commandes)
    - Consulter ses commandes (anterieur & celle dans le pannier)
    - Modifier l'Etat des commandes du pannier (les retirer du pannier/les valdiés -> transformation  en reservation)

    - Consulter les reservations actuelles
    - modifier les reservations actuelles ->
        -> interrompre l'abonnement (=pas de renouvellement à la prochaine periode)
    
    - consulter ses unités (B014-U06 par exemple) et son état (OK / INCIDENT / MAINTENANCE)
    - modifier le "profil" des unités : 
        -> donner un nom
        -> donner une couleur (rouge/bleu/vert...)
        -> donner un type (expl : web/db/stockage...)
       



`Pour un comptable : `

    - se connecter
    - se déconnecter
    
    - consulter la liste des reservations : 
        -> du plus récents au plus vieux
        -> par client

    - consulter la liste des clients
        -> tableau filtrable
        ->possibilité de voir les reservations du clients, avec détails monétaire des offres auxquels il souscrit



`Pour un administrateur :`
    - Toute la partie administrateur se gèrera sur le client lourd
